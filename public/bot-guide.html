Hướng dẫn viết bot

Bot có thể viết bằng JavaScript, C++ hoặc Python để chọn nước đi cho quân của bạn. Hãy bắt đầu từ ví dụ đơn giản, sau đó bổ sung chiến thuật theo cách riêng.

Bắt đầu tạo bot

Bot nhận dữ liệu gì?

Mỗi lượt, chương trình nhận một đối tượng tên input. Các trường hữu ích gồm:

input.pieces.own
Các quân của bạn; mỗi quân có id, type, x và y.
input.pieces.opponent
Các quân của đối thủ trên bàn cờ.
input.target
Tọa độ nhà chính đối phương mà bạn cần đưa quân tới.
input.home
Tọa độ nhà chính của bạn.
input.turn và input.boardSize
Lượt hiện tại và kích thước bàn cờ (9 × 9).
input.rules
Thông tin các loại quân, luật ăn quân và cách di chuyển.

C++ và Python

Với C++ và Python, mã nguồn là một chương trình hoàn chỉnh. Hệ thống gửi toàn bộ bàn cờ vào stdin dưới dạng JSON. Chương trình phải tự chọn quân, tự tính ô đích rồi in đúng một action JSON ra stdout; hãy đưa log vào stderr.

import json, sys
data = json.load(sys.stdin)
own = data.get("pieces", {}).get("own", [])
opponent = data.get("pieces", {}).get("opponent", [])
captures = data.get("rules", {}).get("captures", {})
occupied = {(p["x"], p["y"]): p for p in own + opponent}

for piece in own:
    for dy in (-1, 0, 1):
        for dx in (-1, 0, 1):
            if dx == 0 and dy == 0:
                continue
            x, y = piece["x"] + dx, piece["y"] + dy
            if not (0 <= x < data["boardSize"] and 0 <= y < data["boardSize"]):
                continue
            occupant = occupied.get((x, y))
            if occupant and (occupant["ownerId"] == piece["ownerId"] or captures[piece["type"]] != occupant["type"]):
                continue
            print(json.dumps({"pieceId": piece["id"], "to": {"x": x, "y": y}}))
            raise SystemExit
print("null")

Bạn có thể dùng thư viện JSON có sẵn trong môi trường của ngôn ngữ nếu được hỗ trợ, nhưng không được cài package động trong lúc chạy. Backend sẽ kiểm tra lại toàn bộ luật.

Bot cần trả về gì?

Hãy trả về một đối tượng gồm mã quân và tọa độ đích. Tọa độ đích bắt buộc là một trong 8 ô liền kề xung quanh quân được chọn, giống quân Tướng trong cờ tướng; bot không được tự đi nhiều ô trong một lượt. Bot phải tự tính cặp dữ liệu này, không nhận sẵn danh sách nước đi:

{
  pieceId: move.pieceId,
  to: { x: move.to.x, y: move.to.y }
}

Nếu không có nước đi, trả về null. Backend và game engine sẽ kiểm tra quân thuộc về bot, tọa độ nằm trong bàn, khoảng cách tối đa một ô, quân cùng phe chặn đường, luật Búa–Kéo–Bao và điều kiện thắng; kết quả không hợp lệ sẽ bị từ chối.

Ví dụ bot đầu tiên

Bot dưới đây tự duyệt từng quân và tám ô xung quanh, bỏ qua quân cùng phe và chỉ ăn quân đúng luật:

const own = input.pieces.own || [];
const opponent = input.pieces.opponent || [];
const captures = input.rules.captures || {};
const occupied = new Map([...own, ...opponent].map(p => [p.x + "," + p.y, p]));

for (const piece of own) {
  for (let dy = -1; dy <= 1; dy++) for (let dx = -1; dx <= 1; dx++) {
    if (dx === 0 && dy === 0) continue;
    const x = piece.x + dx, y = piece.y + dy;
    if (x < 0 || y < 0 || x >= input.boardSize || y >= input.boardSize) continue;
    const occupant = occupied.get(x + "," + y);
    if (occupant?.ownerId === piece.ownerId) continue;
    if (occupant && captures[piece.type] !== occupant.type) continue;
    return { pieceId: piece.id, to: { x, y } };
  }
}
return null;

Những điều cần nhớ

  • Bàn cờ có 9 hàng và 9 cột; tọa độ x, y bắt đầu từ 0.
  • Mỗi quân đi tối đa một ô theo một trong tám hướng.
  • Búa ăn Kéo, Kéo ăn Bao, Bao ăn Búa. Hai quân cùng loại hoặc quân đối thủ khắc chế quân đang đi sẽ chặn nước đi.
  • Chạm nhà chính đối phương hoặc ăn hết quân đối phương sẽ thắng.
  • Mỗi lượt, mã bot được chạy độc lập. Đừng dựa vào biến toàn cục để ghi nhớ dữ liệu giữa các lượt.
  • Bot chạy trong môi trường giới hạn; không truy cập tệp hay kết nối mạng. C++/Python phải in đúng một JSON action ra stdout. Bot chỉ đề xuất; backend mới là bên kiểm tra và thực sự di chuyển quân.
  • Hãy bấm Kiểm tra nước đi ở trang tạo bot trước khi lưu bot.
